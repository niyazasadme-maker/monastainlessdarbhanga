# Darbhanga Jindal Stainless Steel & Aluminium Works

One-page website for the shop in Shivdhara, Darbhanga (Bihar), India.
Live at **https://monastainlessdarbhanga.vercel.app**

## Layout

- `index.html` - the whole site (markup, styles and scripts in one file)
- `*.jpg`, `map.png` - photos, referenced from the repo root
- `inter-ui.woff2` - the Inter font

No build step. Hosted on Vercel; every push to `main` deploys automatically.

## Analytics

- **Vercel Web Analytics** - snippet already in `index.html`; enable it in the Vercel project (Analytics tab) for visitors and page views.
- **Microsoft Clarity** - heatmaps, taps, scrolls and session recordings. The snippet sits commented in `index.html`; it goes live once the Clarity project ID replaces `CLARITY_PROJECT_ID`.
